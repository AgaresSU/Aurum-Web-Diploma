# AurumWeb

Дипломный проект — сайт веб-разработчика и консультанта.

На сайте представлены услуги по разработке и поддержке сайтов,
Python-автоматизации и созданию Telegram-ботов. Посетитель может посмотреть
примеры сайтов, выбрать подходящее направление и заполнить заявку на проект.

## Возможности

- главная страница с основными направлениями;
- каталог услуг с подробным описанием и стоимостью;
- каталог примеров сайтов с фильтрацией по категориям;
- открытие интерактивных примеров сайтов;
- выбор примера при заполнении заявки;
- страница отзывов;
- регистрация и вход в личный кабинет;
- профиль клиента и сохранение новых задач;
- адаптивная верстка для компьютеров и мобильных устройств.

## Приложения

- `core` — общие страницы сайта;
- `content` — услуги, отзывы и примеры сайтов;
- `leads` — форма заявки;
- `accounts` — учетные записи пользователей;
- `client_portal` — личный кабинет клиента;
- `projects` — проекты клиентов.

## Технологии

- Python 3.12;
- Django 5.2;
- HTML, CSS и JavaScript;
- SQLite.

## Запуск

```text
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
