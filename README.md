# AurumWeb

Дипломный проект на Django для веб-разработчика и консультанта. Сайт объединяет
публичный каталог услуг, примеры работ, приём заявок, личный кабинет клиента и
рабочий кабинет менеджера.

## Возможности

- страницы услуг, отзывов и примеров сайтов;
- интерактивный просмотр шаблонов на компьютере и телефоне;
- регистрация, подтверждение электронной почты и восстановление пароля;
- заявки и переписка с клиентом;
- проекты с этапами, файлами и согласованиями;
- заказы, счета и история оплат;
- учёт клиентских сайтов, доменов, хостинга и сертификатов;
- рабочий кабинет с клиентами, календарём, поиском и показателями;
- двухфакторная защита учётных записей сотрудников;
- подготовка интеграций с Telegram и Robokassa.

## Структура проекта

- `apps.core` — главная страница, служебные функции и журнал действий;
- `apps.content` — услуги, отзывы и каталог примеров;
- `apps.accounts` — регистрация, вход, профили и безопасность;
- `apps.leads` — заявки и быстрые консультации;
- `apps.projects` — проекты, этапы, файлы и согласования;
- `apps.messaging` — диалоги клиента и менеджера;
- `apps.billing` — заказы, счета, платежи и клиентские сайты;
- `apps.client_portal` — личный кабинет клиента;
- `apps.office` — рабочий кабинет менеджера;
- `apps.integrations` — настройки внешних сервисов и фоновые задачи.

## Технологии

- Python 3.12;
- Django 5.2;
- HTML, CSS и JavaScript;
- SQLite для локальной разработки;
- PostgreSQL для рабочего окружения.

## Запуск проекта

```text
python -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo_content
python manage.py seed_site_templates
python manage.py runserver
```

После запуска сайт доступен по адресу `http://127.0.0.1:8000/`.

Настройки окружения находятся в файле `.env`. Пример заполнения приведён в
`.env.example`.

## Проверка

```text
python manage.py check
python manage.py test
```
